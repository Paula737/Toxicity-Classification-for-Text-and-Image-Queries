## 📌 Overview

This project explores **toxic-content classification** across text and image-query scenarios. It includes an experimental notebook and a dedicated application directory for the toxicity-classification workflow.

## ✨ Project Scope

- Explore approaches for identifying toxic or harmful content in user queries.
- Experiment with toxicity-classification workflows in Jupyter Notebook.
- Organize application code separately from experimentation.

## 📂 Repository Structure

```text
Toxicity-Classification/

```

## 🚀 Getting Started

```bash
git clone https://github.com/Paula737/Toxicity-Classification.git
cd Toxicity-Classification
```

Open **`Task0.ipynb`** to explore the notebook. The **`toxic_content_app/`** folder contains the application code; check its files for the appropriate entry point and required packages before running it.
